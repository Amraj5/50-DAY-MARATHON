# 🧙 Day 01 — Spell Analyzer in Python

This is the Python counterpart of the Day 01 C++ project from the 50-Day Full Stack Engineering Marathon.  
It analyzes a given input "spell" (string) and reports the following insights:

- Total characters
- Vowels
- Consonants
- Digits
- Spaces
- Punctuation (additional Python feature)

## 🐍 Why Python?

This project introduces beginners to:
- String operations and built-in methods
- Control structures and conditions
- Modular function design
- Use of standard libraries like `string`
- Clear, readable syntax for rapid prototyping
