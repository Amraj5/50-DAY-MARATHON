# 🧙 Day 01 — Spell Analyzer in C++

This is a poetic yet functional **string analysis tool** built in C++ as part of the 50-Day Full Stack Engineering Marathon. It analyses a given input string ("spell") to extract and report the following:

- Total characters
- Total digits
- Total spaces
- Total vowels
- Total consonants

## 🔍 What Makes This Special?

The project introduces beginners to:
- String manipulation
- Standard Library usage (`<cctype>`, `<string>`)
- Looping through characters with a range-based for-loop
- Functional programming via modular function design
- Basic CLI interactivity with a story-driven intro
